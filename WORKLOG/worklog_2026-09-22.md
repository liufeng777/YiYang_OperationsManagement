## 任务1：全局页面滚动改造——页面不整页滚动，数据卡片填充剩余高度并内部滚动

### 任务描述

- 整站滚动调整：不再让 page-container 整体滚动；列表类页面最底部的 Table 卡片计算/撑满剩余视口高度，表格自己滚动（如运营首页近期订单、机构管理列表）；
- 系统设置-角色管理：左侧角色列表卡片与右侧角色配置卡片分别竖向滚动；
- 合理压缩 page-container__header 与统计卡片高度，把更多空间留给数据展示。

### 解决方案

- **布局层（`src/layouts/layout.less`）**：`.basic-layout__content` 由 `overflow: auto` 改为 `overflow: hidden`，滚动权下放给 PageContainer（默认模式仍自滚，行为不变）。
- **PageContainer（`src/components/PageContainer`）**：
  - 新增 `fixed` prop → `page-container--fixed`：容器 `overflow: hidden`，body 转纵向 flex、禁止滚动；body 直接子元素 `flex-shrink: 0`；若页面只有单一根容器（`:only-child`），根容器自动撑满并转纵向 flex，内部数据卡片即可填充剩余高度（详情/表单等长内容页面保持默认整页滚动，无需改动）；
  - 头部紧凑化：padding `md lg` → `sm lg`，标题 28/40 → 20/28（复用 title-module 令牌），描述 14 → 12 辅助字号，下边距 md → sm；容器四周 padding xl → lg。
- **表格内部滚动（`src/styles/list-card.less` 新增 `.list-card--fill`）**：纯 CSS 方案，无需逐表传 `scroll.y`——flex 链 `card-body → table-wrapper → spin → table → container`，最终由 `.ant-table-content` 滚动；表头 `position: sticky` 吸附（沿用 list-card 表头底色），分页固定卡片底部。
- **统计卡紧凑化（`src/styles/metric-card.less`）**：body padding 16px，图标 40→32，数值 28/36 → 24/32，数值/标记间距 sm/12px → 2xs/xs。
- **角色管理（`system/Role`）**：`role.less` 改造为 Spin 包装层透传高度 → `.role-manage` 撑满 → 左右两张 Card 等高（grid stretch），`role-list__items` 与 `role-panel__groups` 各自 `overflow-y: auto`，底部分页/操作栏 `flex-shrink: 0`；窄屏（<1200px）改为上下两行 `minmax(160px,1fr) / minmax(240px,2fr)` 仍各自内滚。
- **特殊结构页面**：
  - 机构服务上下架（`service/institution/index.less`）：`__main` grid 撑满，左侧机构面板列表去 520px 上限改 flex 填充滚动，右侧服务表 `list-card--fill`；
  - 集团服务池（`service/list.less`）：`__main` 撑满，分类侧栏高度 100% 内部滚动；

## 任务2：修复所有列表表格溢出无滚动条——FillTable 测量注入 scroll.y

### 任务描述

- 用户反馈：所有 Table 模块溢出后均未出现滚动条（如注册会员列表、操作日志列表），要求检查全局样式。

### 问题定位

- 全局滚动条样式（`src/styles/global.less`）正常，8px 滚动条未隐藏；
- 根因是任务1的 `.list-card--fill` 纯 CSS 方案（flex 链 + `.ant-table-content` overflow + sticky 表头）在 antd 6 实际 DOM 上不生效，表格体始终按内容撑高、把分页挤出可视区，且无任何滚动容器接管。

### 解决方案

- 放弃纯 CSS 猜测，改用 antd 原生 `scroll={{ y }}` 的确定性方案：
  - **新增 `src/components/FillTable/index.tsx`**：泛型组件，props 与 antd Table 完全一致并原样透传；`useLayoutEffect` + `ResizeObserver`（容器尺寸变化）+ `MutationObserver`（分页/数据异步渲染）自动测量容器剩余高度，`scrollY = 容器高 − 表头高（兜底 39px）− 分页高（32+16，pagination=false 时为 0）`，下限 120px；渲染包裹层 `<div class="fill-table">` 并注入 `scroll={{ y: scrollY, ...props.scroll }}`——表头固定、表格体内部滚动、分页固定卡片底部；
  - **`src/styles/list-card.less`**：`.list-card--fill` 删除失效的 spin/table flex 链与 sticky 表头规则，保留卡片 flex 填充，新增 `.fill-table { flex: 1; min-height: 0 }` 与分页 `flex-shrink: 0`；
  - **24 个列表页** `<Table` 全部替换为 `<FillTable`（antd import 同步移除 Table、追加 `@/components/FillTable` 导入），无闭合标签需处理（均为自闭合）。
- 未改动的表格（不在 fixed 布局内，保持默认行为）：order/workOrderTable、refund/detail、finance/reconcile/detail、institution/ServicesTab（2 处）、activity/InstitutionConfigDrawer、service/detail、member/points、member/verify（后两者为待删除 mock）。

## 任务3：修复运营首页「近期订单」滚动高度不对、滚到底内容显示不全

### 任务描述

- 用户反馈：运营首页「近期订单」列表（无分页）滚动高度不对，滚到最下面内容也没显示完全。

### 问题定位

- rc-table 固定表头结构：表格总高 = 表头高 + `maxHeight: scroll.y`，卡片 `.ant-card-body` 为 `overflow: hidden`——`scroll.y` 只要略大于实际可用空间，表格底部即被裁切。
- 根因是 FillTable 中的 `MIN_SCROLL_Y = 120` 强制下限：运营首页底部卡片被指标行、待办/趋势行（208px 固定高）挤压后，剩余高度在普通笔记本视口（如 1366×768）下可能不足 159px（表头 39 + 下限 120），下限把 scrollY 撑大超出实际空间，最后几行被裁掉。无分页只是让该页没有分页器缓冲、问题更易暴露。

### 解决方案

- `src/components/FillTable/index.tsx`：
  - 移除 `MIN_SCROLL_Y` 硬性下限，改为 `Math.max(next, 0)`——scrollY 绝不超过容器实际可用空间；
  - 表头测量改为优先读已渲染的 `.ant-table-header` 包装层 `offsetHeight`（含边框，最精确），退化顺序：`.ant-table-header` → `.ant-table-thead` → 兜底 39px。
