## 任务2：退款详情页渲染审批记录 / 退款渠道记录，并支持部分退款履约展示

### 任务描述

- 需求 1：退款详情接口返回 `approvals` 与 `refund_channel_logs`（见 `refund.ts` 契约），需在详情页渲染；`approvals` 用 Table，`refund_channel_logs` 参照设计稿「协作平台联动」模块评估渲染方式，不合适则另行设计。
- 需求 2：审批部分参照设计稿优化，金额等信息重点突出。
- 需求 3：`order_type === 2`（部分退款）时按 `order_id` 拉取订单，展示 `served_count`（已消费次数）/ `service_count`（总购买次数），表明本次退的是剩余次数费用。
- 设计稿：`退款金额审核详情.png`（退款审核详情页）。

### 解决方案

- **审批记录（`approvals`）**：新增「审批记录」卡片，antd Table 渲染（按 `approve_step` 升序，`rowKey=record_id`）；列：审批步骤（第 N 步）、审批环节（approver_type）、审批人、审批结果（Tag：1-通过 success / 2-拒绝 error，未知回显原始值）、核定退款金额（`refund_amount` 字符串按「分」换算为元，品牌色加粗高亮）、退款渠道、审批意见、审批时间（created_at 秒→毫秒）。
- **退款渠道记录（`refund_channel_logs`）**：设计稿「协作平台联动」为固定五步业务流水线（Steps），而渠道记录是动态日志（通常 1 条，失败重试时多条，含交易单号/失败原因/操作人等），Steps 语义不匹配，改用 **Timeline** 渲染：状态色圆点（4-已退款 绿 / 6-退款失败 红 / 3-退款中 蓝）+ 状态 pill + 渠道 + 金额高亮 + 六宫格字段（触发/完成时间、操作人、渠道退款单号、支付交易单号、微信退款单号），`fail_reason` 危险色、`remark` 辅助色单独成行。
- **金额重点突出**：摘要卡「退款金额」升级为模块标题字号（20px/700）品牌色；审批表与渠道记录中的金额统一 `.amount-highlight` 品牌色加粗；关联订单号改为品牌色可点击链接（原内联硬编码 `#27866B` 移除，样式收敛到 less 变量）。
- **部分退款履约**：`order_type === 2` 时 `orderApi.getOrder(order_id)` 拉取订单，新增「套餐履约情况」卡片：左侧 dashboard 进度盘（已消费/总次数），右侧四项统计（总购买次数 / 已消费次数 / 剩余次数（本次退还，高亮）/ 订单实付金额），卡片副标题标明「部分退款 · 本次退还剩余 N 次服务费用」。
- **存量清理**：删除原文件中已取数但从未渲染的 `memberMap`（会员列表全量拉取）与 `workOrders`（工单列表）相关死代码及 `memberApi` / `workorderApi` / `WorkOrderDTO` 导入，消除既有 TS6133 编译错误；后续如需工单列表可复用 `../order/workOrderTable` 再加回。

## 任务5：注册会员列表/详情完善——机构名称、生日格式、证件号掩码、标签着色

### 任务描述

1. `institution_id` 需拉取机构列表，显示对应机构名称；
2. 会员生日格式为 `1938-06-25T00:00:00+08:00`，需转为 `yyyy-MM-dd`；
3. 会员身份证默认中间 `*` 掩码，旁边眼睛按钮点击后显示完整证件号；
4. 标签 `tag_ids` 需拉取标签列表匹配，按 `tag_name` / `tag_color` 用 Tag 组件渲染。

### 解决方案

- **机构名称**：`list.tsx` 挂载时 `institutionApi.getInstitutions({ page: 1, page_size: 200 })` 构建 `institutionMap`（id → name）；列表「所属机构」列与详情 Drawer 均按 map 显示名称，未匹配回显 `#id`。
- **标签着色**：`api/index.ts` 新增 `tagApi` 导出（tag.ts 的 `getTags`，此前未被引用）；挂载时拉取标签字典构建 `tagMap`（id → tagItem）。`constants.ts` 新增共享函数 `resolveMemberTags`：兼容 `tags`（MemberTagBrief 对象数组 / id 数组）与 `tag_ids` 两种实测返回，优先取字典的 `tag_name` / `tag_color`；列表恢复「标签」列、Drawer 标签项均用 `Tag color={tag_color}` 渲染。
- **生日格式**：Drawer 内 `formatBirthday` 用 dayjs 解析 ISO 后 `format('YYYY-MM-DD')`，非法值回显原始值。
- **证件号掩码**：Drawer 内 `maskIdCard` 保留首尾各 4 位（短号按比例保留）、中间 `*` 替代；眼睛按钮（EyeOutlined / EyeInvisibleOutlined）切换明文，每次打开新会员自动重置为掩码。`.id-card-field` 样式置于 list.less 顶层作用域（Drawer 渲染在 body 级）。
- **数据共享**：`institutionMap` / `tagMap` 由列表页拉取后以 props 传入 Drawer，避免重复请求。
