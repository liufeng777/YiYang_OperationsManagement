
## 任务2：提取 display:grid 表单网格为公共样式 form-grid，统一相邻行上下间距

### 任务描述

- 用户指出任务1改错方向：拥挤的是「上下两行网格之间」的间距（如 service/detail 中 `.editor-grid` 的 `margin-top: 8px`），而非网格内部行距；
- 要求统一所有 display:grid 的 form 表单样式，并将 grid 表单 less 提取为公共样式。

### 解决方案

- **新增公共样式 `src/styles/form-grid.less`**（global.less 已 @import）：
  - `.form-grid`：`display: grid; gap: @spacing-md`；变体 `--two / --three / --four`；`.form-grid__full` 跨整行；
  - **相邻两行网格间距**：`.form-grid ~ .form-grid { margin-top: @spacing-md }`（统一 16px，替代原先 0 / 8px 的拥挤间距）；
  - 网格内 `.ant-form-item { margin-bottom: 0 }`、`.ant-select { width: 100% }`。
- **迁移各页面（tsx 类名替换 + 删除本地重复网格样式）**：
  - service/detail：`.editor-grid > .editor-grid__3` ×4 → 3 个并列 `.form-grid.form-grid--three`（删除空网格行与包装层，行距 8px → 16px）；
  - activity/create：`.create-grid--two/--four` → `.form-grid--two/--four`（原先相邻行间距为 0 → 16px）；
  - system/Agreement：`.edit-field__row` → `.form-grid.form-grid--three`；
  - content/article-edit：`.edit-field__row` → `.form-grid.form-grid--four`，网格内 `.edit-field` 底距归零；
  - system/Help：`.help-card__fields` → `.form-grid.form-grid--three`；
  - Message/TemplatesTab：`.template-drawer__two-col` → `.form-grid.form-grid--two`，Drawer 表单边距规则收窄为直接子选择器避免覆盖公共样式；
  - institution/components/InstitutionBaseFields：`.institution-form__grid--3` ×3 → `.form-grid.form-grid--three`（institution-form.less 仅保留标签样式与 stack 变体）。
- **响应式媒体查询同步更新**：article-edit（--four → 2列/1列）、agreement-edit（--three → 1列）、activity/create、help、service/detail、institution-form（<720px `.form-grid` → 单列）。
- 任务1 中对网格内部行距的调整随迁移统一回 `@spacing-md`；机构详情 `.service-config__grid` 为无 tsx 引用的死代码，未迁移。
