## 任务1：患者端展示内容新增富文本编辑（Tiptap JSON）公共组件

### 任务描述

- 用户需求：为「患者端展示内容」的详情图片与服务内容新增一种交互——富文本编辑、存储 JSON，后期需在微信小程序中渲染；保留现有交互（列表封面、详情图片 ImageSortGrid、服务内容 TextArea），在卡片标题后增加按钮，点击用 Drawer 弹出富文本编辑器；编辑器提取为公共组件；富文本图片走专门上传接口（`POST /upload`），url 存入 JSON。

### 解决方案

- **选型对比（ProseMirror/Tiptap JSON vs Slate JSON）**：选择 Tiptap（ProseMirror JSON），理由：
  1. ProseMirror schema 稳定成熟，文档产生即被 schema 校验，非法结构无法落库——跨端（小程序）渲染可靠性的关键；
  2. Tiptap 可直接 `getJSON()` / `getHTML()`，HTML 可对接小程序 `rich-text` 组件，社区已有大量 ProseMirror JSON → 小程序渲染实践；
  3. Slate JSON 结构完全自定义、无 schema 约束，且 API 变动频繁，跨端渲染需自行约定与维护。
- **新增公共组件 `src/components/RichTextEditor/`**：
  - Props：`value?: JSONContent | null`、`onChange?: (json) => void`、`minHeight?: number`；value 仅作初始内容，编辑中不回写，避免光标跳动
  - 扩展：StarterKit + Image；`shouldRerenderOnTransaction: true` 保证工具栏高亮实时
  - 工具栏：加粗 / 斜体 / H2 / H3 / 无序列表 / 有序列表 / 插入图片 / 撤销 / 重做
  - 图片插入：`uploadApi.uploadFile(file)` 拿 `url` 后 `setImage({ src })` 写入 JSON；当前无后端环境，catch 降级为 `URL.createObjectURL` 本地预览（TODO：后端就绪后移除）
  - 占位提示用空态 + 聚焦态本地实现，未引入 Placeholder 扩展，保持依赖精简
  - 样式全部使用 variables.less 变量
- **服务详情页接入**（`src/pages/service/detail/index.tsx`）：
  - 「患者端展示内容」卡片 header 右侧新增「富文本编辑」按钮（`editor-card__header-action`，margin-left: auto）
  - 点击打开 720 宽 Drawer（destroyOnHidden），内嵌 RichTextEditor + 底部取消/确定
  - state：`richContent`（已确认 JSON）、`richDraft`（Drawer 内草稿）；确定后写回 richContent（TODO：保存服务时随表单提交，如 content_json 字段）
  - 现有封面 / 详情图片 / 服务内容控件全部保留未动

## 任务2：RichTextEditor 合并增强 + 富文本 Demo 页

### 任务描述

- 发现仓库已有 `src/components/RichTextEditor.tsx`（HTML 版，协议编辑页在用），与新建的目录版重名导致导入解析冲突；需合并为单一组件。
- 用户反馈：① 图片上传动作与预览必须在编辑器内可用（文件服务器存图，编辑器内完成上传与预览）；② 工具栏不够丰富，需要文字颜色等能力。
- 用户要求：给出一个富文本 Demo 并给出 JSON 数据。

### 解决方案

- **组件合并**（`src/components/RichTextEditor.tsx` 单文件版，删除目录版）：
  - `value` 同时支持 HTML 字符串与 ProseMirror JSON（`type==='doc'` 判定）；`onChange(html, json)` 双格式回传；`export type { JSONContent }`
  - 修复 StarterKit v3 与独立 Link 扩展重复注册问题：Link/Underline 已由 StarterKit v3 内置，改为 `StarterKit.configure({ link: { openOnClick: false } })`
- **图片上传闭环**：选图后立即 `URL.createObjectURL` 本地预览插入 → 后台调 `uploadApi.uploadFile` → 成功后 `doc.descendants` 定位该 image 节点并 `setNodeMarkup` 替换为服务器 url（JSON 中最终存服务器 url）；接口不可用时保留本地预览并提示
- **工具栏增强**：新增 H3、下划线、删除线、文字颜色（Popover 预设 6 色[设计变量] + 自定义取色器 + 清除颜色，基于 TextStyle+Color 扩展）、背景高亮（Highlight）、清除格式；`shouldRerenderOnTransaction: true` 保证高亮态实时
- **Demo 页**：`src/pages/demo/rich-text/index.tsx`，隐藏路由 `/system/rich-text-demo`；预置「上门助浴服务」示例 JSON（含标题/列表/加粗/斜体/彩色文字/图片节点），编辑时实时展示 JSON 与 HTML 输出
