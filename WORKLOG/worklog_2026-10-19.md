## 任务：运营参数值编辑控件按类型统一（string→Input / number→InputNumber / bool→Switch）

### 需求描述

- type 为 string 时用 Input，number 时用 InputNumber，bool 时用 Switch（存 'true'/'false'），整体交互合理统一。

### 变更内容（src/pages/system/Settings/settings.tsx）

- 新增 `coerceValue(type, value)`：类型切换时兜底参数值——bool 仅允许 'true'/'false'（非法默认 'false'），number 仅允许数值（否则清空），string 保留原值；
- 行内编辑：值控件以草稿类型（draft.type）为准，超管在类型列切换 Select 时同步 coerce 值，保证控件与类型一致；保存 payload 使用 draft.type + coerce 后的 value（修复此前类型变更不生效的问题）；
- 新增参数弹窗：bool 由 Select 改为 Switch（valuePropName=checked，存 'true'/'false'），与行内编辑一致；切换类型时重置值为对应类型合法默认值；bool 无必填校验（恒有值）；提交时 null 兜底为空串；
- 清理未使用的 SearchOutlined 导入（修复 TS6133）。
