## 任务1：系统设置下新增「支付设置」子路由及微信支付配置页面

### 任务描述

- 用户需求：在系统设置模块下新增「支付设置」子路由，并按设计稿实现微信支付配置页面。
- 设计稿内容：页面包含微信商户基础信息、安全凭证、支付与退款回调三大卡片；右侧边栏包含渠道运行状态、连接测试、最近操作记录。

### 解决方案

- **路由（routes.tsx）**：在 `/system` children 中新增 `path: 'payment'` 子路由，指向 `@/pages/system/Payment/payment`。
- **页内导航（SystemTabs.tsx）**：tabs 数组追加 `{ key: '/system/payment', label: '支付设置' }`，与其他系统设置子页面保持一致。
- **API（settings.ts）**：新增支付相关类型与接口：
  - `WechatPayConfig`：微信支付配置 DTO（商户号、AppID、API V3 密钥、私钥、证书、回调 URL 等）。
  - `PaymentOperationLog`：操作日志项。
  - `PaymentConnectionTestResult`：连接测试结果。
  - 接口：`getWechatPayConfig`、`updateWechatPayConfig`、`testWechatPayConnection`、`getPaymentLogs`。
- **页面组件（payment.tsx）**：
  - 左侧主内容：微信商户基础信息（支付渠道、商户号、AppID，支持编辑）、安全凭证（API V3 密钥/商户私钥/商户证书，支持更新/上传/查看）、支付与退款回调（固定 URL，支持复制）。
  - 右侧边栏：渠道运行状态（Switch 启停）、连接测试（模拟异步测试并记录最近结果）、最近操作记录（mock 日志列表）。
  - 编辑商户号/AppID 使用 Modal 弹窗。
- **样式（payment.less）**：左右分栏布局（主内容 flex:1 + 侧边栏 320px），卡片表面、信息行、渠道状态条、测试结果区、操作日志列表等样式，响应式适配 ≤1024px。

## 任务2：消息模板页面新增/编辑改为 Drawer 并对齐设计稿

### 任务描述

- 用户需求：将消息模板页面的新增/编辑从 Modal 改为右侧 Drawer，并按设计稿重新设计表单布局与内容。

- **表格列调整**：模板名称 → 固定触发事件 → 启用渠道 → 操作，移除不再展示的编码/类型/内容/状态/更新时间列（设计稿表格仅展示名称/触发事件/渠道/操作）。
- **筛选栏调整**：搜索框提示改为「请输入模板名称或触发事件」；下拉增加「全部渠道」筛选（站内/微信/短信）。
- **Drawer 表单**：
  - 标题动态切换：新建/编辑；副标题展示当前模板名 + 「业务触发消息」。
  - 两列布局：业务类型（disabled）+ 触发节点（disabled）。
  - 接收对象：Select mode=multiple，8 个选项（下单人/服务对象/报名人等）。
  - 微信服务消息模板 ID：必填输入框。
  - 消息内容预览：卡片样式展示模板变量（`{{订单号}}` 等）。
  - 底部注解区：两坨蓝色注解卡片，分别说明一期触发节点和接收对象与发送规则。
  - 底部按钮：取消 + 保存并启用（保存后自动启用）。
- **样式（TemplatesTab.less）**：Drawer 标题/副标题、两列网格、消息预览卡片、注解区（蓝色底色+边框）、底部按钮区。

## 任务3：对照 API 文档修改消息通知管理四个 Tab 交互

### 任务描述

- 用户需求：根据《运营后台端-API设计.md》§9（9.1 站内消息、9.2 消息模板管理、9.3 短信记录、9.4 系统公告）的定义，修改消息通知管理四个 Tab 的交互逻辑与字段。
- 涉及文件：`MessagesTab.tsx`、`AnnouncementsTab.tsx`、`TemplatesTab.tsx`、`SmsLogsTab.tsx`、`message.ts`。

### 解决方案

#### MessagesTab（9.1 站内消息）
- **发送方式**：新增「发送方式」Radio 选择（群发 / 指定用户）。
  - 群发：无需选择接收者，直接发送。
  - 指定用户：展开「接收用户」多选下拉，支持同时选择多个用户。
- **表格列调整**：新增「操作」列，支持「查看详情」与「推送微信」。
- **消息详情 Modal**：点击「查看详情」弹出 Modal，展示消息标题、内容、发送方式、接收对象、发送时间、微信推送状态等完整字段。
- **API 对齐**：发送接口字段 `send_type`（1=群发 / 2=指定用户）、`receiver_ids`（指定用户时必填数组）。

#### AnnouncementsTab（9.4 系统公告）
- **Modal 表单补充字段**：
  - `target_ids`：定向发布机构多选（Select mode=multiple），空数组表示全部机构。
  - `expires_at`：过期时间 DatePicker，公告到达过期时间后自动下架。
  - `cover_image`：封面上传组件（Upload + 预览），支持图片上传。
- **发布/撤回交互**：改为二次确认 Modal，确认后调用改状态接口（`status: 1` 发布 / `status: 0` 撤回），而非直接删除。
- **表格列**：展示封面缩略图、公告标题、定向机构（全部/部分）、发布状态、过期时间、发布时间、操作（编辑/发布/撤回/删除）。

#### TemplatesTab（9.2 消息模板管理）

#### API 层（message.ts）
