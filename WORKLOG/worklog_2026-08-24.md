# 工作日志 2026-08-24

## 任务1：按 API 设计文档完善接口层（src/api）

### 任务描述

- 用户需求：依据《运营后台端-API设计 v1.4》《共通-API设计 v1.1》（已复制至 `docs/api/`）完善各模块接口，缺少接口的交互最后列出。
- 现状盘点：原有 9 个模块（dashboard/institution/service/activity/order/refund/finance/content/system）为 mock 风格路径（如 `/service/list`），页面仅 `import type` 引用类型、不调用接口函数，因此可在保留页面类型的前提下整体重构。

### 解决方案

- **策略**：每个模块上半部分保留页面展示用类型（mock，页面正在使用），下半部分新增 DTO（snake_case、UTC 秒）与接口函数，严格对齐文档契约；删除无人调用的 mock 路径函数。
- **共通契约**（`src/types/api.d.ts`）：新增 `ApiPageParams`（page/page_size/keyword）、`ApiPageResult`（list/total/page/page_size）、`BatchResult`、`UploadResult`、`CommonStatus`；`request.ts` 请求头加 `X-Client-Type: web-admin`。
- **路径约定**：baseURL 已含 `/api`（vite proxy），代码路径以 `/admin/...` 开头；上传为共通 `/upload`。
