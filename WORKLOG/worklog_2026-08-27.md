## 任务4：重构「患者端展示内容」排布（封面 / 详情图片 / 服务内容同行紧邻）

### 任务描述

- 用户需求：重构服务编辑页「患者端展示内容」区域的 less：
  1. 列表封面、详情图片、服务内容三者在同一行且紧挨着（现状：详情图片区无论图片多少都占满剩余空间，把服务内容挤到最右边）；
  2. 详情图片列表图片够多时先占满父元素剩余宽度再换行 —— 即最大宽度为父元素剩余宽度，正常宽度为内容实际宽度。

### 解决方案

- **根因**：`.editor-upload--detail` 原为 `flex: 1 1 auto`，`flex-grow: 1` 使其恒占满剩余宽度。

  - 图片少 → 宽度 = 图片网格实际内容宽度，服务内容紧随其后；
  - 图片多 → flex 收缩至父容器剩余宽度封顶，内部 `repeat(auto-fill, 132px)` grid 自动换行。
- **配套重构**：
  - `.editor-content` 区域补充布局说明注释，标签样式（封面 / 详情图片 span + 服务内容 Form label）合并为一处；
  - 删除 `.editor-upload` 中重复的 `> span` 标签规则，仅保留 `&__tip` 底部提示并提升为独立选择器；
  - 封面块注释更正为「不参与伸缩」；
  - 1200px 媒体查询删除对 flex 容器无效的 `.editor-content { grid-template-columns }` 残留；
  - 720px 纵向堆叠时 `.editor-upload--detail` 同步 `width: 100%`（原仅 textarea）。

## 任务5：修复详情图片区「未占满剩余宽度却已换行」问题

### 任务描述

- 用户反馈：任务4 改造后 `.editor-upload--detail` 虽未占满父元素剩余空间（符合预期），但详情图片仍提前换行（不符合预期：应先占满剩余宽度再换行）。

### 解决方案

- **根因**：`ImageSortGrid` fixed 变体使用 `grid-template-columns: repeat(auto-fill, 132px)`；grid 在收缩适应（shrink-to-fit / flex 基准尺寸）上下文中，auto-fill 的轨道数不会按「全部图块排一行」参与 max-content 计算，导致父级 `flex: 0 1 auto` 的基准宽度偏小、图片提前换行。
- **修复（ImageSortGrid/index.less）**：fixed 变体由 grid auto-fill 改为 `display: flex; flex-wrap: wrap`，图块与添加块 `flex-shrink: 0; width: 132px`。flex 容器的 max-content 即「全部图块排一行的宽度」，父级行为完全可控：
  - 图片少 → 详情区宽度 = 内容实际宽度，服务内容紧随其后；
  - 图片多 → 详情区先占满父容器剩余宽度，内部再换行。
- fixed 变体全站仅 `src/pages/service/detail.tsx` 使用（已确认），不影响 fluid 场景（活动详情图）。

| src/components/ImageSortGrid/index.less | 修改 | fixed 变体 grid auto-fill → flex-wrap，图块/添加块固定 132px |
| src/components/ImageSortGrid/index.tsx | 修改 | variant 注释同步更新 |

## 任务6：面包屑一级导航可点击返回 + 路由跳转问题排查修复

### 任务描述

- 用户需求：没有子 menu 的一级导航（机构管理 / 活动管理 / 订单中心 / 退款管理 / 财务对账），进入详情页后，面包屑点击前一项（如「机构管理 / 机构详情」中的「机构管理」）应可返回列表页；并顺便检查面包屑跳转的其他优化项。

### 排查结果

1. **面包屑首项恒不可点击（主问题）**：`HeaderBar.tsx` 中 `index === 0 || index === list.length - 1` 均渲染纯文本，两级面包屑（机构管理 / 机构详情）因此没有任何可点项。
2. **`/system` 无默认页**：若一级面包屑直接跳 `/system`，路由表无匹配子路由会渲染空白，需落到第一个可见二级导航（用户管理）。
3. **服务池 3 处跳转会命中 404（顺手发现的优化项）**：
   - `service/list.tsx` 编辑按钮 `/service/list/detail/:id` → 路由实为 `/service/detail/:id`；
   - `service/list.tsx` 新建按钮 `/service/list/detail/new` → 同上；
   - `service/detail.tsx` 返回服务池 `/service/list` → 路由默认页为 `/service`。

### 解决方案

- **HeaderBar.tsx**：面包屑渲染条件改为「仅末级不可点击」，一级导航与中间层级均可点击跳转（`navigate(item.path)`）。
- **menu.tsx `findBreadcrumb`**：一级面包屑增加落点解析——有默认页（`''` 子路由）用一级路径；无默认页（系统设置）落到第一个 `!hideInMenu` 的二级导航路径（`/system/account`），避免点击后空白页。
- **service/list.tsx**：编辑 / 新建跳转改为 `/service/detail/${id}`、`/service/detail/new`。
- **service/detail.tsx**：返回服务池改为 `/service`。
