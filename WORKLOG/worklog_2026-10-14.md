# 工作日志 2026-10-14

## 任务：三个页面的患者端手机预览渲染封面图与图文详情（富文本 JSON → HTML）

### 需求描述

- 服务项目编辑页、机构基础信息表单、活动新建/编辑页三个页面，在「患者端展示详情」中上传封面图、配置图文详情（ProseMirror JSON）后，手机预览需实时渲染封面与富文本内容；
- 富文本 JSON 需合理渲染成 HTML 展示在手机预览界面。

### 变更内容

**新增共用渲染组件**

- `src/components/RichDetailPreview/index.tsx`（+ index.less）：只读图文详情渲染器——value 为 RichTextEditor 产出的 ProseMirror JSON 字符串，用与编辑器一致的扩展集合（StarterKit 含 link / TextStyle / Color / Highlight / Image）经 `@tiptap/core` 的 `generateHTML` 生成 HTML，`dangerouslySetInnerHTML` 渲染；非 JSON 按历史 HTML 字符串回退；导出 `isRichDetailEmpty` 判断空内容（空文档/仅空段落且无图片）；样式按 320-328px 手机容器调校（图片 max-width 100%、h2/h3/列表/链接/高亮）。

**服务详情页（service/detail/index.tsx + index.less）**

- 手机预览 hero 区接入封面图（`has-cover` 变体：图片铺满 + 渐变遮罩 + 标题叠白字），无封面保持原浅蓝占位；
- 「服务介绍」占位块（is-blue/is-warm）替换为「图文详情」区块，`RichDetailPreview` 实时渲染，未配置时显示空态提示；
- 手机框改 flex 布局，新增 `&__scroll` 滚动区（hero + body 可上下滚动，底部操作栏固定）。

**机构表单（institution/components/InstitutionInfoForm.tsx + .less）**

- hero 同样接入封面图（has-cover 变体）；body 中「已配置图文详情（富文本内容见小程序渲染）」占位文案替换为 `RichDetailPreview` 实时渲染；
- 新增 `&__scroll` 滚动区（预留底部 CTA 72px），CTA 补白底避免内容透出。

**活动创建页（activity/create/index.tsx + index.less）**

- `renderPhonePreview`：hero 接入封面图（has-cover 变体）；两个 DETAIL IMAGE 占位块替换为 `RichDetailPreview`（白底 `&__detail` 区块），未配置时保留一个占位提示块；右侧实时预览与「手机预览」弹窗共用同一渲染函数，均生效；
- 新增 `&__scroll` 滚动区包裹 hero/tags/info/详情，底部报名栏固定。
